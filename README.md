# 캣점프 할로윈 · 밤의 현상금 사냥

**[바로 플레이](https://topkide.github.io/halloween2026/)**

움직이는 유령을 제한된 탄약으로 사냥하는 모바일 세로형 프로토타입입니다. 실루엣·관절 동작·이동 방식이 다른 5종의 일반 유령, 황금·시간·탄약 유령, 폭탄·먹물 방해 요소가 등장합니다. 랜덤 현상금 표적과 배수에 따라 같은 실력으로도 판마다 다른 보상을 노릴 수 있습니다.

- 기본 60초, 총 30발(장전 5발 + 예비 25발), 5발 소진 시 2.2초 자동 장전
- 8초마다 현상금 표적과 배수 교체 (×2 / ×3 / ×5 / ×8 / ×10)
- 표적 명중: 종별 기본 점수 + 200 × 현상금 배수
- 황금 유령 +1,200점, 시간 유령 +100점과 5초, 탄약 유령 예비탄 +2발(총 보유 한도 30발)
- 유령 체류 약 2.1~3초, 0.5초마다 한 마리씩 등장, 동시 최대 8마리
- 위로 출현 후 정지, 수평/수직 이동, 커졌다 작아짐, 수평/수직 복귀의 6가지 행동
- 폭탄 명중 또는 탄약 완전 소진 시 종료, 먹물은 2.3초 동안 게임 화면 전체 가림
- 총성·탄도·착탄 섬광·파편·탄피와 명중 반응
- 설정에서 시간·장전·등장 간격 조정, 최고 기록 초기화

사격은 터치/클릭이며 수동 장전 버튼과 R 단축키는 없습니다. 탭을 벗어나면 자동으로 일시정지합니다. 현상금 표적은 상단 수배서를 보고 구분합니다. 광고 보상 기능은 제거했습니다.

## 개발

```sh
python3 -m http.server 8765 --directory site
node --test site/tests/*.test.mjs
python3 site/tests/check-ui.py
```

빌드 없이 정적 파일로 실행합니다. `main`의 `site/**` 변경은 기존 GitHub Pages 워크플로가 검증 후 같은 주소에 배포합니다.

소스 구조와 예산은 [site/README.md](site/README.md), 구체적인 규칙은 [site/GAME_RULES.md](site/GAME_RULES.md)에 있습니다. 이전 기억력 게임은 Git 이력으로 남아 있으며 현재 페이지에서는 실행하지 않습니다.
