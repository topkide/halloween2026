# 캣점프 할로윈 · 황금 현상금 웨이브 사냥

**[바로 플레이](https://topkide.github.io/halloween2026/)**

짧게 나타나는 유령을 사격하여 웨이브 목표를 채우고, 황금 유령의 현상금 코인을 모으는 모바일 세로형 프로토타입입니다.

- 장전과 탄약 제한 없이 사격, 헛발 한 번에 남은 시간 2초 차감
- 한 판 전체 60초, 웨이브 안내와 일시정지 중에는 시간 정지
- 첫 웨이브 목표 8마리, 다음 웨이브마다 2마리 증가(최대 24마리)
- 웨이브 시작 전 황금 유령의 현상금 배수와 실제 지급 코인 공개
- 황금 유령 한 마리: 100코인 × 배수(×2 / ×3 / ×5 / ×8 / ×10)
- 일반 유령은 처치 목표를 채우고, 황금 유령은 처치 수와 코인을 함께 지급
- 0.5초마다 한 마리, 동시 최대 8마리, 6가지 간단한 이동 패턴
- 시간이 0이 되거나 폭탄을 맞히면 종료, 종료 사유와 코인·완료 웨이브·명중률 표시

터치/클릭으로 사격합니다. 탭을 벗어나면 자동으로 일시정지합니다. 일반 5종·황금 유령과 폭탄·먹물 방해 요소가 등장합니다. 먹물은 2.3초 동안 게임 화면 전체를 가립니다. 광고 기능은 없습니다.

## 개발

```sh
python3 -m http.server 8765 --directory site
node --test site/tests/*.test.mjs
python3 site/tests/check-ui.py
```

빌드 없이 실행하는 정적 사이트입니다. `main`의 `site/**` 변경은 GitHub Actions 검증 후 같은 GitHub Pages 주소에 배포됩니다.
