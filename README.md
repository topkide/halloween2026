# 캣점프 할로윈 · 황금 현상금 웨이브 사냥

**[바로 플레이](https://topkide.github.io/halloween2026/)**

짧게 나타나는 유령을 사격하여 웨이브 목표를 채우고, 종류별 점수와 황금 보너스로 최고 점수에 도전하는 모바일 세로형 프로토타입입니다.

- 탄약·재장전 대기 없이 즉시 연속 사격, 헛발 한 번에 남은 시간 2초 차감
- 한 판 전체 60초, 웨이브 안내와 일시정지 중에는 시간 정지
- 첫 웨이브 목표 8마리, 다음 웨이브마다 2마리씩 계속 증가(9웨이브 24마리 → 10웨이브 26마리 → 20웨이브 46마리, 상한 없음)
- 웨이브 시작 전 배수가 빠르게 회전·감속한 뒤 확정, 보너스 점수 공개
- 황금은 웨이브당 최대 2마리 처치(설정에서 1~10마리 조절), 놓친 황금은 횟수 차감 없이 재등장 가능
- 황금은 임의 위치에 완전히 등장한 후 0.24초 뒤 동서남북 중 한 방향으로 직선 이동, 기본 2.5초마다 등장 추첨(기본 50% → 최대 강화 100%, 첫 등장은 보장)
- 황금 유령 한 마리: 500점 × 배수(×2 / ×3 / ×5 / ×8 / ×10)
- 일반 유령은 난이도에 따라 100 / 150 / 200 / 250 / 300점, 황금은 1,000~5,000점의 보너스
- 일반 유령은 0.23초 간격, 동시 최대 8마리, 일반 6가지 이동과 황금 전용 직선 이동
- 시간이 0이 되면 종료, 종료 사유와 총점·일반 점수·황금 보너스·완료 웨이브·명중률 표시

터치/클릭으로 사격합니다. 탭을 벗어나면 자동으로 일시정지합니다. 일반 5종과 황금 유령만 등장합니다. 황금 유령은 등장 위치에서 0.24초 보인 뒤 이동합니다. 이동은 첫 웨이브 0.6~0.8초이며 후반으로 갈수록 빨라집니다. 방해 요소는 없습니다. 광고 보상은 실제 SDK 연결 전의 체험 기능입니다.

## 강화와 재화

사냥 전 강화소에서 황금 등장 확률·강화 코인 획득량을 각각 최대 10레벨까지 올립니다. 첫 강화는 20코인이며 이후 비용이 10코인씩 증가합니다. 판 종료 시 처치 1마리당 강화 코인은 기본 1개이며, 획득량 강화마다 1개씩 늘어 최대 11개입니다. 점수 100점당 이벤트 코인 1개를 받으며 이 재화에는 강화 보너스를 적용하지 않습니다. 기존 재장전 강화 비용은 전액 반환하고 재화 강화 레벨은 새 효과로 이어받습니다. 잔액과 레벨은 브라우저에 저장합니다.

## 개발

```sh
python3 -m http.server 8765 --directory site
node --test site/tests/*.test.mjs
python3 site/tests/check-ui.py
```

### 광고 아이템: 샷건

- 업그레이드 화면의 `샷건 장착`에서 다음 사냥 한 판에 사용할 샷건을 받습니다. 현재 광고 SDK 연결 전이므로 클릭 즉시 보상을 적용하는 버튼입니다.
- 장착은 화면을 닫거나 새로고침해도 유지됩니다. 플레이 기회 사용과 함께 한 번만 소비하며, 플레이 기회가 없으면 소비하지 않습니다. 판이 끝나면 일반 사격으로 돌아갑니다.
- 터치한 지점과 원형 범위에 닿는 유령을 동시에 처치합니다. 사격 반경은 `site/ghost-aim.mjs`의 `SHOTGUN.radius`(사냥터 너비 400 기준 72)에서 조절합니다. 화면 크기에 비례하며 그림의 투명 여백은 주변 명중 판정에서 제외합니다.
- 한 마리 이상 명중하면 헛발 시간 감소가 없습니다. 모두 빗나간 경우에만 한 발당 기존 2초 감소를 적용합니다. 탄약 제한과 재장전은 없습니다.
- 한 발에 여러 마리를 잡으면 각 유령의 강화 코인과 황금 보너스를 모두 합산합니다. 마지막 한 발은 현재 웨이브의 보상으로 한 번에 정산한 후 한 번만 회복·전환하며, 초과 처치 수는 다음 웨이브에 이월하지 않습니다.
- 산탄, 원형 범위 표시, 명중 섬광을 제한된 캔버스 효과로 표시합니다. 기기 모션 감소 설정을 따릅니다.

### 업그레이드 / 결과 UI

- 메인 게임 시작 → 업그레이드 → 게임 시작 순서입니다. 강화 화면에는 보유 강화 코인, 세 가지 아이콘·현재 효과·구매 비용, 샷건 장착·유령 X2 광고 버튼과 플레이 기회가 표시됩니다. 기존 30단계 수치와 비용은 유지합니다.
- 결과창은 강화 코인과 완료한 웨이브를 위에, 상품 교환소 코인을 중앙에 크게 표시합니다. `보상 2배`는 광고 연동 전 체험이며, 이미 지급된 이번 판 호박 코인만 한 번 더 지급합니다. 강화 코인 및 기존 보유 재화에는 배수를 적용하지 않습니다.
- 보상 수령 기록은 저장되어 중복 지급을 막습니다. `뒤로`는 메인으로, `재도전`은 업그레이드 화면으로 돌아갑니다. 실제 게임 시작 때만 기회를 사용합니다.
- 모달 배치는 `site/event-dialogs.css`, 보상 중복 방지는 `site/upgrades.mjs`, 강화 이미지 세 장은 `site/assets/upgrade-*.png`에 있습니다.

### 광고 아이템: 유령 X2

- 업그레이드 하단은 `샷건 장착` · `유령 X2` · `게임 시작` 세 버튼입니다. 광고 보상 체험을 각각 받을 수 있고 두 효과를 함께 적용할 수 있습니다.
- 유령 X2는 다음 사냥 한 판 동안 일반 유령 등장 간격을 절반으로 줄입니다(기본 0.23초 → 0.115초). 동시 등장 한도도 8 → 16마리로 늘어 샷건 연속 처치를 지원합니다. 황금 추첨 주기·처치 한도·보상은 기존 설정을 따릅니다.
- 두 광고 보상은 창 닫기/새로고침 뒤에도 준비 상태로 유지됩니다. 기회 사용을 저장한 뒤 한 판에만 소비하고, 기회 부족이나 저장 실패 때에는 유지합니다. 재도전에서는 다시 광고 보상을 받아야 합니다.
- 게임 하단에는 받은 효과만 `샷건 / 적용 중`, `유령 X2 / 적용 중`으로 표시하며 웨이브 준비 및 일시정지 동안에도 표시를 유지합니다.
- 저장된 등장 간격과 기존 재화/강화를 변경하지 않습니다. `event-core.mjs`의 준비 상태와 `hunt-core.mjs`의 판별 소환 배수로 처리합니다.

### 웨이브 시작 현상금 안내

- 기존 양피지 포스터와 황금 유령 그림은 유지합니다. 위에는 `Wave N`, 포스터 제목에는 `유령 현상금`, 그림 위에는 호박 코인과 `+보상량`, 아래에는 `X배수`를 표시합니다.
- 보상량은 황금 유령 한 마리의 실제 호박 코인 현상금이며, 웨이브 기본 보상·강화·추첨 배수를 반영합니다(첫 웨이브 기본 보상 10 × X5 = +50).
- 추첨 중에는 보상량을 `+?`로 숨기고 배수 확정과 동시에 공개합니다. 기존 1.8초 추첨과 1.1초 결과 표시, 웨이브 클리어 시 보상 확정 규칙을 유지합니다.

### 타격 효과와 획득 코인 표시

- 일반·황금 유령은 짧은 백색 섬광 뒤 원래 그림이 여섯 조각으로 터지고, 빠른 충격파·불꽃 궤적·짧은 압력 구름이 이어집니다. 샷건은 각 대상에 동일한 파괴 효과를 적용하며 화면 흔들림은 없습니다.
- 하단 명중/빗나감 안내와 상단의 추가 코인 알림을 제거했습니다. 잡은 위치에 종류별 실제 강화 코인 `+1`~`+5`만 표시하고, 샷건도 대상별 숫자를 따로 표시합니다. 황금 현상금은 같은 위치에 금색 `+보상량`으로 표시하며 클리어 때 확정되는 기존 정산 규칙을 유지합니다.
- 일반 사격은 실제 1911 총성, 샷건은 실제 Benelli Nova 총성에 저음과 짧은 잔향을 더한 소리를 사용합니다. 명중은 별도의 짧은 충격음이며, 헛발에는 명중음을 재생하지 않습니다. 연속 사격의 소리 크기는 공유 압축기로 제한합니다. 광고 효과·명중 판정·생성·시간·보상 수치는 유지합니다.
- 단일 캔버스에 최대 24개 폭발(각 16개 이하 파편), 32개 숫자, 4개 샷건 확산만 유지합니다. 모션 감소 설정에서는 이동·분해·충격파를 생략하고 짧은 고정 효과와 코인 숫자를 남깁니다.

### 한 판에 한 번 이어하기

- 한 판의 첫 종료 후 `이어하기` 창을 표시합니다. `뒤로` 또는 Escape는 최종 결과창으로 이동합니다. `이어하기` 버튼은 추가 안내 팝업 없이 바로 계속합니다.
- 추가 플레이 기회를 쓰지 않고 종료된 웨이브 번호·퇴치 목표·현상금 배수를 유지한 채, 그 웨이브의 처치 수와 황금 처치 한도를 0부터 다시 시작합니다. 시간은 설정된 시작 시간(기본 90초)까지 회복합니다.
- 샷건과 유령 X2를 함께 적용합니다. 이미 사용 중인 효과는 유지하고 없는 효과는 추가하며 배수를 중첩하지 않습니다. 이어하기는 같은 runId에서 한 번만 가능하고 두 번째 종료는 결과창으로 바로 이동합니다.
- 이전 완료 웨이브 보상과 이미 잡은 일반 유령의 강화 코인은 유지합니다. 미완료 웨이브의 미확정 황금 보너스는 다시 시작할 때 버립니다. 보상은 최종 결과창에서 한 번만 정산하며 결과 광고 2배도 전체 판에 한 번만 적용합니다.
- 새 판을 시작하면 이어하기 횟수를 다시 받을 수 있습니다. 시안의 고양이와 유령 그림은 투명 PNG로 분리하여 `assets/continue-friends.png`에 사용합니다.

### 광고 보상과 간결한 표시

- 샷건·유령 X2·플레이 기회 +3·결과 보상 2배·이어하기는 버튼 클릭 즉시 적용합니다. 추가 확인 팝업은 띄우지 않으며, 기존 저장 실패 되돌리기와 중복 보상 방지를 유지합니다.
- 준비된 샷건과 유령 X2, 수령한 보상 2배 버튼은 아이콘 없이 `적용 중`만 표시합니다. 인게임 하단에는 `샷건 / 적용 중`, `유령 X2 / 적용 중`으로 표시합니다.
- 사냥터 화면 흔들림과 HUD 숫자 확대를 제거했습니다. 결과창의 `완료한 웨이브`·광고 보상 안내, 강화창의 다음 단계 효과와 하단 유지 안내를 제거했습니다.

### 총성과 업그레이드 화살표

- 전투 사운드는 웨이브 준비 중 미리 불러오고, 로딩 실패 또는 첫 로딩 중에도 즉시 대체 총성을 재생합니다. 소리가 늦게 재생되지는 않으며, 재생 중인 전투 소리는 최대 24개로 제한합니다. 음소거 설정을 유지합니다.
- 총성 파일과 CC0 원본 출처는 site/assets/audio/CREDITS.md, 전투 사운드 처리는 site/combat-audio.mjs에 있습니다.
- 강화창 뒤로가기 화살표는 SVG로 바꾸고 제목과 동일한 높이의 영역에 정렬합니다. 작은 화면과 가로 화면에서도 제목과 함께 높이가 조절됩니다.

### GAME OVER와 10초 시간 경고

- 종료 시 유령·타격 효과·획득 숫자를 즉시 지우고, 사냥 화면 상단 중앙에 투명 GAME OVER 이미지를 1.8초간 표시합니다. 이후 한 판의 첫 종료는 이어하기, 이어하기를 이미 사용한 종료는 결과창으로 넘어갑니다.
- 남은 시간이 10초 이하일 때 빨간 시간 표시가 1초 주기로 점멸합니다. 일시정지·웨이브 준비 중에는 점멸하지 않고, 시간 회복으로 10초를 넘거나 게임이 종료되면 해제됩니다. 모션 감소 설정에서는 빨간 표시만 유지합니다.
- 종료 이미지는 assets/game-over-halloween-v1.png이며 사냥 진입 전에 미리 불러옵니다.

### 메인 장식과 상품 교환소

- 메인 배경 위에 표시하던 구매 유령·호박 코인 장식을 제거했습니다.
- 상품 교환소는 기존 버튼 모습으로 표시하며 클릭해도 창이나 안내가 열리지 않습니다. 교환 UI와 버튼 동작 연결을 제거했습니다.

### 모바일 버튼 색상과 뒤로가기 버튼

- 메인의 광고 버튼은 녹색, 게임 시작은 주황색 단색 배경과 대비가 높은 글자색을 직접 지정합니다. 모바일 기본 버튼 외형을 해제하고 활성 버튼에만 정상 불투명도를 적용합니다. 실제 기회 상한에 따른 비활성 상태는 유지합니다.
- 광고·시작·이어하기 버튼에는 color-scheme: only light를 적용해 브라우저 자동 색상 변경에 대응합니다. Android WebView의 작성자 테마 인식을 위해 color-scheme 메타 태그도 제공합니다.
- 강화창의 뒤로가기 버튼은 제목과 같은 행에서 같은 높이로 배치하고, 사각 테두리 안에 채워진 주황색 화살표를 표시합니다.
- 참고: https://developer.chrome.com/blog/auto-dark-theme/ · https://developer.android.com/develop/ui/views/layout/webapps/dark-theme

### 미션과 특별 고양이

- 메인 하단은 상품 교환소 · 미션 · 게임 시작 순서이며, 미션 버튼은 별도의 스크롤 패널을 엽니다. 아이콘·진행 바·현재/목표 수치·진행 중 또는 완료 상태를 표시하고, 전체 완료 진행과 보상 받기 영역은 하단에 고정합니다.
- 미션은 총 9개입니다. 뚱보·길쭉이·성큼이·주렁이·납작이 각각 500마리, 황금 유령 100마리, 시간 회복·황금 유령 확률·웨이브 보상 증가 각각 30레벨입니다.
- 유령 미션은 업데이트 이후 실제 성공한 처치부터 종류별로 누적합니다. 샷건의 모든 대상과 마지막 웨이브 처치도 각각 집계하고, 헛발·중복 표적·일시정지 중 입력·놓친 유령은 제외합니다. 이어하기·재도전·새로고침 후에도 누적 수치를 유지합니다.
- 기존 저장에는 종류별 처치 이력이 없어 과거 총 처치 수로 미션 기록을 추정하지 않습니다. 기존 강화 레벨은 즉시 반영하며, 재화·기회·기록·광고 준비 상태를 유지합니다.
- 9개 미션을 모두 완료하면 특별 고양이 받기를 활성화합니다. 추가 팝업 없이 보상 보유 상태를 저장하고 획득 완료로 표시하며, 수령 기록은 재시작과 새로고침 후에도 중복 수령을 막습니다. 저장 실패 시 보상을 수령 처리하지 않습니다.
- 규칙과 저장 정규화는 site/missions.mjs, UI는 site/missions.css 및 site/app.mjs에 있습니다. 보상 썸네일은 사용자 시안의 해당 부분을 SVG viewBox로 표시합니다.

### 미션 목록의 스크롤 단서

- 미션 패널을 열 때마다 목록 맨 위로 돌아갑니다. 기본 배치는 네 카드 전체와 다음 카드의 절반이 보이도록 표시 영역 높이에서 카드 높이를 계산합니다. 짧은 표시 영역에서는 읽을 수 있는 카드 크기를 확보하면서도 다음 카드가 반쯤 보이는 구성을 유지합니다.
- 상품 교환소 버튼 앞의 호박 코인 아이콘을 제거했습니다.

### 브라우저 공통 기본 설정

- 시작 시간 90초, 기본 시간 회복 10%, 한 판 총 회복 한도 30초, 유령 등장 간격 0.23초, 황금 등장 간격 2.5초, 웨이브당 황금 한도 2마리를 모든 브라우저의 기본값으로 사용합니다.
- 저장 버전 8보다 오래된 브라우저 기록은 첫 진입 시 이 6개 설정만 한 번 맞추고 즉시 저장합니다. 코인·강화·미션·보상 수령·기회·광고 준비·최고 기록은 유지하며, 이후 직접 변경한 설정은 다음 진입에도 유지합니다.

### 유령 무리의 배치와 이동

- 일반 유령은 중앙을 포함한 9개 구역에 3마리씩 모여 나오고, 다음 무리는 떨어진 구역으로 이동합니다. 유령 X2는 같은 무리를 6마리로 늘려 샷건의 다중 처치를 유지합니다.
- 진입·복귀 유령은 중앙으로 모이지 않고 각 무리의 위치에서 정지합니다. 가까운 가장자리로 들어오고 돌아가며, 직선 이동 유령도 무리마다 다른 가로·세로 경로를 사용합니다.
- 중앙 고정 연타보다 무리 위치를 따라 조준하는 플레이가 유리하도록 배치만 조정했습니다. 기존 크기·사격 범위·등장 간격·시간·보상과 저장 기록은 그대로입니다.
