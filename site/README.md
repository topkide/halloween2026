# 유령 소탕 대작전! · 할로윈 이벤트 프로토타입

배경과 유령에 섬세한 픽셀 아트를 사용하고, UI는 일반 글꼴·둥근 버튼·얇은 테두리·일러스트 코인으로 구성합니다. 저해상도 도트 격자와 강제 픽셀 확대는 사용하지 않습니다.

메인 → 사냥 준비(강화 3종) → 웨이브 사냥 → 보상 → 메인 흐름입니다.
메인은 제목·아이콘·숫자 중심으로 표시하며 이벤트 영문 문구, 하단 분위기 문구·최고 기록, 사냥꾼 배지와 지갑의 재화 이름은 표시하지 않습니다. 배지 소유 기록과 최고 기록 데이터는 유지합니다.
보내주신 세로형 시안에 맞춰 특별 패키지, 우측의 은색/호박 코인, 300m 기회 진행, 기회 +3, 교환소와 시작 버튼을 배치했습니다.

## 재화와 강화

- 은색 유령 코인: 일반 유령 처치 보상. 뚱보 1 / 주렁이 2 / 길쭉이 3 / 성큼이 4 / 납작이 5개. 강화 코인 획득량 강화는 제거하여 종류별 보상만 지급합니다.
- 호박 코인: 웨이브 클리어 기본 10개에서 다음 웨이브마다 5개 증가. 상점 강화 효과를 반영한 뒤 정수 내림합니다.
- 황금 유령: 해당 웨이브 기본 보상 × 추첨 배수(2, 3, 5, 8, 10)를 추가 적립. 그 웨이브를 클리어해야 확정합니다. 미완료 웨이브 보너스만 소멸하며 앞선 확정 보상과 은색 코인은 유지합니다.
- 강화 3종: 시간 회복(10%→30%), 황금 등장 확률(50%→100%), 웨이브 보상(+0%→+200%, 최종 3배). 각 0~30레벨이며 효과는 30단계에 걸쳐 선형 증가합니다. 비용은 20부터 레벨마다 +10, 한 종류 완성에 총 4,950개입니다.
- 시간 회복 강화는 매 웨이브 남은 시간에 적용하며 기존 판당 회복 한도(기본 30초)를 따릅니다. 설정의 기본 회복률은 강화 전 수치이며 30레벨에서는 최대 30%입니다. 웨이브 보상 강화는 기본 보상과 황금 현상금에 함께 적용합니다.
- `upgrades.mjs`의 BALANCE와 GHOST_COINS에서 비용·상한·지급량을 조정합니다.
- 이전 점수 필드는 기존 엔진 회귀 검사 호환용으로 남아 있지만 화면·신규 보상·최고 웨이브 기록에 사용하지 않습니다.

## 인게임 UI

상단 첫 줄은 시간을 중앙에 표시한 붉은 게이지와 일시정지 버튼입니다. 둘째 줄에는 왼쪽 웨이브와 처치 수/목표, 가운데 황금 유령과 배수, 오른쪽 이번 판 강화 코인을 배치합니다. 아래 약 8.4%는 추후 광고 아이템을 위한 빈 공간입니다. 일반 유령 처치 즉시 상단 강화 코인 합계가 갱신되며, 실제 종류별 지급량을 `+N`으로 850ms 표시합니다. 빠른 연속 처치 표시도 최대 4개만 유지하며 다음 웨이브를 여는 마지막 처치 표시가 중간에 지워지지 않습니다. 사운드 설정은 일시정지 창에 있습니다. 웨이브 시작에는 큰 현상수배 포스터 안에서 배수를 추첨하며, 시작 시간 기본값은 90초이며, 클리어 시 남은 시간의 10%를 회복하고 실제 회복량을 다음 웨이브 안내 위에 표시합니다. 판당 누적 회복 한도는 30초이며 회복률과 한도는 설정에서 조절합니다. 강화 창에서 현재 효과와 다음 단계 효과를 소수 첫째 자리까지 확인할 수 있습니다.

겹친 유령은 아틀라스 알파 마스크로 보이는 그림부터 판정합니다. 앞 유령의 투명한 여백이 뒤 유령에 대한 명중을 가로채지 않으며, 실제로 비어 있는 여백은 기존의 관대한 버튼 범위를 유지합니다. 황금 유령의 우선 표시, 좌우 반전과 그림 비율도 반영합니다. 처치 대상 DOM을 이펙트 전에 즉시 제거하고 백색 잔상은 100ms 이내로 제한합니다.

## 사냥

기본 90초, 무제한 즉시 사격, 헛발 −2초. 일반 유령 생성 간격 0.23초, 최대 8마리입니다. 첫 목표 8마리부터 웨이브마다 +2, 최대 24마리. 폭탄·먹물·재장전은 없습니다.

황금은 먼저 0.24초 제자리에 나타나고 동서남북 중 무작위 방향으로 빠르게 이동합니다. 기본 2.5초마다 확률 추첨하며 첫 등장은 확정입니다. 주기는 웨이브 전환 시 유지되고 안내/정지 중에는 멈춥니다. 한 웨이브 최대 2마리 성공 처치이며 놓친 유령은 한도를 소진하지 않습니다. 간격과 한도는 메인의 프로토타입 설정에서 조정 가능합니다.

웨이브 안내는 1.8초 배수 회전 + 1.1초 결과 표시입니다. 추첨 표시 전 실제 보상을 숨기며 준비 중 플레이 시간이 줄지 않습니다. 단일 RAF, 최대 8개 유령과 8개 동시 타격 효과, 재사용 오디오 잡음 버퍼, 80ms HUD 갱신을 사용합니다. 명중은 유령의 백색 잔상·탄착 섬광·종류별 파편·명중 마커, 헛발은 탄흔·먼지·붉은 조준 표시로 구분합니다. 효과는 단일 Canvas에 그리며 최대 12개 파편/사격, 700ms 수명, DPR 최대 2를 적용합니다. 마지막 처치 효과도 웨이브 전환에서 유지합니다. 모션 감소 설정에서는 파편·반동·긴 궤적을 생략하고 정적인 피드백을 남깁니다. 두 번째 손가락과 후속 click 중복 발사, 잡은 유령 재활성화를 막습니다. 탭을 벗어나면 일시정지합니다.

## 프로토타입 범위와 저장

처음 플레이 기회 5개, 최대 30개. 사냥 시작 시 1개를 소비합니다. 일반게임 300m 달성과 광고 기회 +3은 외부 서비스 연결 전 체험 버튼입니다. 특별 패키지에 실제 결제는 없습니다. 상품 교환소는 메인에 표시되는 장식 3종을 교환하는 시제품입니다. 이벤트 기간은 설정 예정으로 표시합니다. 설정에서 체험 코인을 받을 수 있습니다.

`progressVersion: 6`, 저장 키 `catjump-wave-score-v1`. 코인, 강화, 기회/거리, 교환 장식, 최고 웨이브, 결과, 설정을 같은 객체로 저장합니다. 구버전 재화·황금/웨이브 보상 강화 단계·정산 ID는 유지합니다. 폐기된 재장전 강화 및 강화 코인 획득량 강화는 당시 구매 비용을 각각 최초 한 번 환불하며 새 시간 회복 강화는 0레벨에서 시작합니다. 각 판 runId로 보상 중복 정산을 막고, 구매·입장 저장 실패 시 차감하지 않습니다. 기존 기본 시간 60초는 처음 한 번 90초로 전환하며 다른 사용자 지정 시간과 저장된 재화·강화는 유지합니다. 서버 저장·실제 광고·원본 일반게임 연동은 없습니다.

화면은 동적 뷰포트와 안전 영역에 맞춰 페이지 스크롤 없이 표시합니다. 짧은 화면에서는 안내 영역을 압축하고 메인 상단의 톱니 버튼으로 설정에 진입합니다. `tests/layout-preview.html`은 여러 크기의 실제 iframe 뷰포트로 메인·강화·게임 표시를 확인하는 개발용 페이지입니다.

### 광고 아이템: 샷건

- 사냥 준비 화면의 `광고로 받기`에서 다음 사냥 한 판에 사용할 샷건을 받습니다. 현재 광고 SDK 연결 전이므로 안내 후 보상 수령을 체험하는 버튼입니다.
- 장착은 화면을 닫거나 새로고침해도 유지됩니다. 플레이 기회 사용과 함께 한 번만 소비하며, 플레이 기회가 없으면 소비하지 않습니다. 판이 끝나면 일반 사격으로 돌아갑니다.
- 터치한 지점과 원형 범위에 닿는 유령을 동시에 처치합니다. 사격 반경은 `site/ghost-aim.mjs`의 `SHOTGUN.radius`(사냥터 너비 400 기준 72)에서 조절합니다. 화면 크기에 비례하며 그림의 투명 여백은 주변 명중 판정에서 제외합니다.
- 한 마리 이상 명중하면 헛발 시간 감소가 없습니다. 모두 빗나간 경우에만 한 발당 기존 2초 감소를 적용합니다. 탄약 제한과 재장전은 없습니다.
- 한 발에 여러 마리를 잡으면 각 유령의 강화 코인과 황금 보너스를 모두 합산합니다. 마지막 한 발은 현재 웨이브의 보상으로 한 번에 정산한 후 한 번만 회복·전환하며, 초과 처치 수는 다음 웨이브에 이월하지 않습니다.
- 산탄, 원형 범위 표시, 명중 섬광을 제한된 캔버스 효과로 표시합니다. 기기 모션 감소 설정을 따릅니다.
