## 상태와 저장

상태는 `ready → briefing → playing`이며 목표 달성 시 `briefing`으로 돌아갑니다. `paused`는 직전 상태를 기억하고 같은 단계로 복귀합니다. `ended` 이후에는 사격·보상·시간이 변하지 않습니다. 브리핑은 1.8초 추첨과 1.1초 결과 확인으로 나뉩니다. 엔진의 bounty-reveal 이벤트에서 확정 결과를 공개하고, 큰 프레임 간격에서도 결과 확인 구간을 건너뛰지 않습니다. 브리핑 중 경과한 시간은 플레이 타이머에서 차감하지 않습니다. 모든 유령은 처치 목표에 포함하며 일반 유령은 100~300점, 황금 유령은 500점 × 웨이브 배수를 지급합니다. 총점과 일반/황금 점수를 함께 집계합니다. 황금 유령은 임의 위치에서 첫 프레임부터 완전히 보이며 GOLD_APPEAR_DURATION(0.24초) 동안 좌표를 고정합니다. 이후 동서남북 중 하나로 직선 이동합니다. 이동 시간 GOLD_MOVE_DURATION(0.6~0.8초)에만 웨이브 속도 배율이 적용되고, 등장 단계는 후반에도 줄어들지 않습니다. 웨이브별 황금 처치 수 waveGold는 실제 명중에서만 증가하고 다음 웨이브·재시작에서 초기화됩니다. waveGold와 현재 화면의 황금 수 합계를 한도 이하로 유지하여 초과 처치를 막습니다. 도망간 황금은 처치 수를 올리지 않고 등장 자리를 반환합니다. 일반 유령은 기존 간격으로 등장하며, 황금은 goldSpawnLeft가 0일 때 우선 생성됩니다. goldInterval은 기본 2.5초이며 추첨 시점부터 다시 셉니다. 첫 황금은 확정 생성하고 이후에는 강화에 따른 50~100% 확률을 적용합니다. 실패한 추첨도 한 주기를 소비합니다. 웨이브가 바뀌어도 남은 간격을 유지하고, 일시정지·브리핑에서는 멈춥니다. 처치 한도나 화면 제한에 막히면 한 번만 대기하며 밀린 등장을 누적하지 않습니다. goldChance는 업그레이드 효과로 계산하며 일반 유령 생성과 분리합니다. 폭탄·먹물은 등장·입력·화면·음향에서 제거했습니다.

저장 키는 `catjump-wave-score-v1`입니다. `progress.mjs`에서 이전 코인 버전의 설정과 사운드를 이어받되, 등장 간격은 0.23초로 바꿉니다. 이전 최고 코인·결과는 점수에 섞지 않고 기존 키에 보존합니다. 새 점수 버전의 기록과 설정은 다음 접속에도 유지합니다. 황금 처치 한도 goldLimit은 기본 2, 설정 범위는 1~10입니다. 등장 간격 goldInterval은 기본 2.5초, 설정 범위는 1~30초입니다. 기존 저장에 값이 없으면 각각 기본값으로 보완합니다. 별도의 서버 저장이나 결제는 없습니다.

`progressVersion: 3`와 economy(강화 코인·이벤트 코인·레벨·정산된 판 ID)를 같은 저장 객체에 기록합니다. 구버전 기본 4초 간격은 최초 전환 시 2.5초로 변경하며 다른 사용자 지정값과 기록은 보존합니다. 기존 결과에는 보상을 소급하지 않습니다. `upgrades.mjs`의 BALANCE에서 비용·최대 레벨·효과·보상 기준을 조정합니다. 각 강화는 최대 10레벨이며 비용은 20부터 10씩 증가합니다. 처치 1마리당 강화 코인은 기본 1개, 획득량 레벨마다 +1개(최대 11개)입니다. 100점당 이벤트 코인 1개를 지급하며 이벤트 코인에는 강화 효과를 적용하지 않습니다. 재장전 강화는 제거하고 기존 구매 비용을 한 번 전액 반환합니다. 기존 재화 강화 레벨은 새 코인 획득량 효과로 이어받습니다. 이미 정산한 판과 이벤트 코인은 그대로 보존합니다. runId로 중복 정산을 막고, 구매 저장 실패 시 잔액과 레벨을 되돌립니다.

## 렌더링과 입력

단일 requestAnimationFrame에서 상태와 좌표를 갱신합니다. 유령 최대 8마리, 사격 효과 노드 최대 12개(착탄 6개와 탄피 6개)이며 효과는 650ms 안에 제거합니다. 잡음 오디오 버퍼는 한 번 만들어 재사용합니다. HUD는 80ms 간격으로 갱신하며 값이 바뀔 때만 텍스트를 씁니다. 현상금 그림은 고정합니다. 회전 숫자열은 웨이브마다 한 번 만들고 기존 RAF에서 transform만 갱신합니다. 연출용 숫자는 게임 RNG를 사용하지 않아 실제 배수 확률이나 다음 유령 등장에 영향을 주지 않습니다.

pointerdown으로 즉시 사격하고 뒤따르는 click은 중복 발사하지 않습니다. 비주 포인터(두 번째 손가락)는 무시합니다. 재장전과 발사 대기 없이 연속 사격할 수 있으며 한 판 시작 시 강화 레벨을 복사합니다. 키보드 활성화와 Pointer Events 미지원 환경도 지원합니다. 브리핑·결과·일시정지에서는 사격을 막습니다. 탭이 숨겨지면 플레이와 브리핑 모두 일시정지합니다.

## 검증과 실행

```sh
node --test site/tests/*.test.mjs
python3 site/tests/check-ui.py
python3 -m http.server 8765 --directory site
```

GitHub Actions는 규칙과 UI 검사를 통과한 버전을 Pages로 배포합니다. 브라우저에서는 사전 현상금 안내, 처치 진행, 웨이브 전환, 종류별 점수 지급, 헛발 시간 차감, 일시정지, 종료·재시작을 확인합니다.
