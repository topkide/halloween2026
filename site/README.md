# 황금 현상금 웨이브 사냥 · 소스 안내

| 파일 | 역할 |
| --- | --- |
| index.html | 코인·황금 현상금·웨이브 안내·목표 진행·결과 화면 |
| style.css | 반응형 화면, 관절 움직임, 사격 효과, 현상금 안내 |
| app.mjs | 입력, DOM, 오디오, 일시정지, 설정, 로컬 저장 |
| hunt-core.mjs | 웨이브 상태 전환, 처치 목표, 헛발 시간 차감, 코인, 등장 |
| ghost-art.mjs | 일반 5종·황금 유령 SVG |
| tests/hunt-core.test.mjs | 상태 전환, 보상, 시간, 중복 입력, 예산 검증 |
| tests/check-ui.py | DOM ID와 로컬 파일 참조 검사 |

## 상태와 저장

상태는 `ready → briefing → playing`이며 목표 달성 시 `briefing`으로 돌아갑니다. `paused`는 직전 상태를 기억하고 같은 단계로 복귀합니다. `ended` 이후에는 사격·보상·시간이 변하지 않습니다. 브리핑 중 경과한 시간은 플레이 타이머에서 차감하지 않습니다. 모든 유령은 처치 목표에 포함하며 황금 유령만 코인을 지급합니다. 황금 유령은 0.7~0.9초 출현하고 웨이브 속도 배율이 적용되어 최단 0.5초입니다. 폭탄·먹물은 등장·입력·화면·음향에서 제거했습니다.

저장 키는 `catjump-wave-hunt-v1`입니다. 기존 `catjump-bounty-hunt-v1` 점수와 구분하여 코인 기록을 저장하며, 이전 데이터에서 사운드 설정만 이어받습니다. 별도의 서버 저장이나 결제는 없습니다.

## 렌더링과 입력

단일 requestAnimationFrame에서 상태와 좌표를 갱신합니다. 유령 최대 8마리, 사격 효과 노드 최대 12개(착탄 6개와 탄피 6개)이며 효과는 650ms 안에 제거합니다. 잡음 오디오 버퍼는 한 번 만들어 재사용합니다. HUD는 80ms 간격으로 갱신하며 값이 바뀔 때만 텍스트를 씁니다. 현상금 그림은 고정합니다.

pointerdown으로 즉시 사격하고 뒤따르는 click은 중복 발사하지 않습니다. 키보드 활성화와 Pointer Events 미지원 환경도 지원합니다. 브리핑·결과·일시정지에서는 사격을 막습니다. 탭이 숨겨지면 플레이와 브리핑 모두 일시정지합니다.

## 검증과 실행

```sh
node --test site/tests/*.test.mjs
python3 site/tests/check-ui.py
python3 -m http.server 8765 --directory site
```

GitHub Actions는 규칙과 UI 검사를 통과한 버전을 Pages로 배포합니다. 브라우저에서는 사전 현상금 안내, 처치 진행, 웨이브 전환, 코인 지급, 헛발 시간 차감, 일시정지, 종료·재시작을 확인합니다.
