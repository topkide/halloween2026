# 유령이 숨은 밤 · 소스 수정 안내

이 폴더는 [캣점프 할로윈 게임](https://topkide.github.io/halloween2026/)의 실행 소스입니다. 현재 규칙은 [GAME_RULES.md](GAME_RULES.md)를 참고하세요.

## 변경할 파일 선택

| 수정 내용 | 파일 |
| --- | --- |
| 기본 기억 시간·사격 시간·콤보·연출 수치 | `balance-default.json` |
| 밸런스 항목·허용 범위·JSON 검증 | `balance-config.mjs` |
| 밸런스 편집 화면·저장/불러오기 | `balance-editor.mjs` |
| 배치·난이도·콤보 계산 | `game-core.mjs` |
| 화면 연결·터치·진행·효과음·저장 | `app.mjs` |
| 화면 요소·문구·접근성 구조 | `index.html` |
| 크기·색상·픽셀 효과·애니메이션 | `style.css` |
| 방·하얀 유령·뿔 유령 그림 | `assets/room.png`, `target.png`, `decoy.png` |
| 수집품 이름·픽셀 아이콘 | `collections.mjs`, `assets/collection-*.svg` |

필요한 파일을 작게 수정하고 검증하는 방식으로 유지합니다. 새 ZIP으로 폴더 전체를 교체하거나 기존 게임 코드를 다시 생성하지 않습니다. 이전 프로토타입은 Git 이력에서 확인할 수 있습니다.

## 밸런스 수정

- **브라우저에서 시험:** 밸런스 화면에서 수치를 변경하고 적용합니다. 현재 브라우저에 저장되며 다음 판부터 사용합니다.
- **다른 브라우저에 전달:** JSON 저장 후 다른 브라우저에서 불러오고 적용합니다.
- **공통 기본값 변경:** 확인한 수치를 `balance-default.json`에 반영하고 커밋·푸시합니다. 기본값을 다른 소스 파일에 복제하지 않습니다.
- **새 기본값 확인:** 이전 사용자 설정이 남아 있다면 밸런스 화면에서 기본값을 복원하고 적용합니다.

시간이 최솟값에 도달하는 배치는 `difficulty.rampRounds`로 정하며 기본값은 24입니다. 노출·사격 시간은 첫 배치의 1.60초·2.80초에서 줄어 24번째부터 0.45초·0.85초를 유지합니다. 콤보 간격은 0.22초이며 READY는 첫 배치 0.80초, 이후 0.65초로 고정합니다. 격자는 3×3에서 5회, 4×4에서 7회 진행하고 13번째부터 5×5를 유지합니다. 빈자리 사격은 `difficulty.missPenalty`(기본 0.40초)만큼 시간을 차감하고 콤보를 끊습니다.

기록·사운드·밸런스·기회와 수집품·구슬은 브라우저 로컬 저장입니다. 주소나 브라우저가 다르면 자동 공유되지 않습니다. 희귀 출현 확률(5%), 판당 수집 제한(2개), 이어하기(1회), 광고 체험(3초)은 `app.mjs`의 진행 로직에 있습니다. 실제 광고를 연결할 때는 `previewAd`를 보상형 SDK의 시청 완료 콜백으로 교체해야 합니다.

코인 단가는 `game-core.mjs`의 `coinsPerGhost`에서 5배치마다 1씩 올립니다. `app.mjs`는 이번 판 최고 도달 배치와 코인 총액을 잡은 횟수와 별도로 보관해 이어하기 때 단가가 내려가지 않도록 합니다. 정산과 2배 보상은 횟수가 아닌 코인 총액을 사용합니다.

기존 `memory-room v1` JSON과 저장된 밸런스는 계속 사용할 수 있습니다. 이전 `rampSeconds` 형식과 옛 기본 노출·사격 값은 최신 기본값으로 변환합니다. 제거된 `haunt` 항목은 무시하며, 옛 기본 READY(0.25초·0.12초)와 브라우저에 저장된 기본 콤보 간격 0.45초도 갱신합니다. 나머지 사용자 수치는 유지합니다.

`missPenalty`가 없는 이전 DB에는 기본 차감량을 보충합니다. 유효한 옛 6×6 DB에서 유령 수가 새 상한을 넘으면 5×5(최대 합 24마리)에 맞춰 줄이되 시간·콤보 설정은 보존합니다. 그 외 잘못된 값은 거부합니다.

## 실행과 검증

아래 명령은 **저장소 루트** 기준입니다.

```sh
python -m http.server 8765 --directory site
node --test site/tests/*.test.mjs
node site/tests/gameplay.test.cjs
```

[로컬 게임](http://localhost:8765/)에서 고정된 자리의 빠른 연속 사격, 짧은 노출, 빈자리 시간 차감, 뿔 유령 즉시 실패, 콤보 시간 회복, 다음 배치 전환을 확인합니다. 모든 타격 이펙트는 터치를 통과시켜야 하며, 파편·연기·안개가 겹친 자리도 연속으로 누를 수 있어야 합니다. 화면과 연출을 바꿨다면 세로형 모바일 크기와 기기의 움직임 줄이기 설정에서도 확인합니다.

## 배포

`main`에 `site/**` 변경을 푸시하면 기존 **Deploy GitHub Pages** 워크플로가 이 폴더를 배포합니다. 빌드 단계는 없으며 저장소 루트의 Pages 설정이나 워크플로는 기존 구성을 유지합니다. 배포 절차는 [루트 README](../README.md)에 있습니다.
