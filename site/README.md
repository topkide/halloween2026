| 파일 | 역할 |
| --- | --- |

| style.css | 반응형 화면, 관절 움직임, 사격 효과, 현상금 안내 |
| app.mjs | 입력, DOM, 오디오, 일시정지, 설정, 로컬 저장 |

## 상태와 저장

상태는 `ready → briefing → playing`이며 목표 달성 시 `briefing`으로 돌아갑니다. `paused`는 직전 상태를 기억하고 같은 단계로 복귀합니다. `ended` 이후에는 사격·보상·시간이 변하지 않습니다. 브리핑은 1.8초 추첨과 1.1초 결과 확인으로 나뉩니다. 엔진의 bounty-reveal 이벤트에서 확정 결과를 공개하고, 큰 프레임 간격에서도 결과 확인 구간을 건너뛰지 않습니다. 브리핑 중 경과한 시간은 플레이 타이머에서 차감하지 않습니다. 모든 유령은 처치 목표에 포함하며 일반 유령은 100~300점, 황금 유령은 500점 × 웨이브 배수를 지급합니다. 총점과 일반/황금 점수를 함께 집계합니다. 황금 유령은 0.7~0.9초 출현하고 웨이브 속도 배율이 적용되어 최단 0.5초입니다. 폭탄·먹물은 등장·입력·화면·음향에서 제거했습니다.

저장 키는 `catjump-wave-score-v1`입니다. `progress.mjs`에서 이전 코인 버전의 설정과 사운드를 이어받되, 등장 간격은 0.23초로 바꿉니다. 이전 최고 코인·결과는 점수에 섞지 않고 기존 키에 보존합니다. 새 점수 버전의 기록과 설정은 다음 접속에도 유지합니다. 별도의 서버 저장이나 결제는 없습니다.

## 렌더링과 입력

단일 requestAnimationFrame에서 상태와 좌표를 갱신합니다. 유령 최대 8마리, 사격 효과 노드 최대 12개(착탄 6개와 탄피 6개)이며 효과는 650ms 안에 제거합니다. 잡음 오디오 버퍼는 한 번 만들어 재사용합니다. HUD는 80ms 간격으로 갱신하며 값이 바뀔 때만 텍스트를 씁니다. 현상금 그림은 고정합니다. 회전 숫자열은 웨이브마다 한 번 만들고 기존 RAF에서 transform만 갱신합니다. 연출용 숫자는 게임 RNG를 사용하지 않아 실제 배수 확률이나 다음 유령 등장에 영향을 주지 않습니다.

pointerdown으로 즉시 사격하고 뒤따르는 click은 중복 발사하지 않습니다. 키보드 활성화와 Pointer Events 미지원 환경도 지원합니다. 브리핑·결과·일시정지에서는 사격을 막습니다. 탭이 숨겨지면 플레이와 브리핑 모두 일시정지합니다.

## 검증과 실행

```sh
node --test site/tests/*.test.mjs
python3 site/tests/check-ui.py
python3 -m http.server 8765 --directory site
```

GitHub Actions는 규칙과 UI 검사를 통과한 버전을 Pages로 배포합니다. 브라우저에서는 사전 현상금 안내, 처치 진행, 웨이브 전환, 종류별 점수 지급, 헛발 시간 차감, 일시정지, 종료·재시작을 확인합니다.
