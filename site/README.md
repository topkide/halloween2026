# 유령 소탕 대작전! · 할로윈 이벤트 프로토타입

배경과 유령에 섬세한 픽셀 아트를 사용하고, UI는 일반 글꼴·둥근 버튼·얇은 테두리·일러스트 코인으로 구성합니다. 저해상도 도트 격자와 강제 픽셀 확대는 사용하지 않습니다.

메인 → 사냥 준비(강화 3종) → 웨이브 사냥 → 보상 → 메인 흐름입니다.
보내주신 세로형 시안에 맞춰 특별 패키지, 우측의 은색/호박 코인, 300m 기회 진행, 기회 +3, 교환소와 시작 버튼을 배치했습니다.

## 재화와 강화

- 은색 유령 코인: 일반 유령 처치 보상. 뚱보 1 / 주렁이 2 / 길쭉이 3 / 성큼이 4 / 납작이 5개. 획득량 강화가 마리마다 더해집니다.
- 호박 코인: 웨이브 클리어 기본 10개에서 다음 웨이브마다 5개 증가. 상점 강화 효과를 반영한 뒤 정수 내림합니다.
- 황금 유령: 해당 웨이브 기본 보상 × 추첨 배수(2, 3, 5, 8, 10)를 추가 적립. 그 웨이브를 클리어해야 확정합니다. 미완료 웨이브 보너스만 소멸하며 앞선 확정 보상과 은색 코인은 유지합니다.
- 강화 3종: 황금 등장 확률(50%→100%), 일반 유령 추가 강화 코인(+0→+10), 웨이브 호박 코인(+0%→+100%). 각 최대 10레벨, 비용 20부터 레벨마다 +10.
- `upgrades.mjs`의 BALANCE와 GHOST_COINS에서 비용·상한·지급량을 조정합니다.
- 이전 점수 필드는 기존 엔진 회귀 검사 호환용으로 남아 있지만 화면·신규 보상·최고 웨이브 기록에 사용하지 않습니다.

## 사냥

60초, 무제한 즉시 사격, 헛발 −2초. 일반 유령 생성 간격 0.23초, 최대 8마리입니다. 첫 목표 8마리부터 웨이브마다 +2, 최대 24마리. 폭탄·먹물·재장전은 없습니다.

황금은 먼저 0.24초 제자리에 나타나고 동서남북 중 무작위 방향으로 빠르게 이동합니다. 기본 2.5초마다 확률 추첨하며 첫 등장은 확정입니다. 주기는 웨이브 전환 시 유지되고 안내/정지 중에는 멈춥니다. 한 웨이브 최대 2마리 성공 처치이며 놓친 유령은 한도를 소진하지 않습니다. 간격과 한도는 메인의 프로토타입 설정에서 조정 가능합니다.

웨이브 안내는 1.8초 배수 회전 + 1.1초 결과 표시입니다. 추첨 표시 전 실제 보상을 숨기며 준비 중 플레이 시간이 줄지 않습니다. 단일 RAF, 최대 8개 유령과 8개 동시 타격 효과, 재사용 오디오 잡음 버퍼, 80ms HUD 갱신을 사용합니다. 명중은 유령의 백색 잔상·탄착 섬광·종류별 파편·명중 마커, 헛발은 탄흔·먼지·붉은 조준 표시로 구분합니다. 효과는 단일 Canvas에 그리며 최대 12개 파편/사격, 700ms 수명, DPR 최대 2를 적용합니다. 마지막 처치 효과도 웨이브 전환에서 유지합니다. 모션 감소 설정에서는 파편·반동·긴 궤적을 생략하고 정적인 피드백을 남깁니다. 두 번째 손가락과 후속 click 중복 발사, 잡은 유령 재활성화를 막습니다. 탭을 벗어나면 일시정지합니다.

## 프로토타입 범위와 저장

처음 플레이 기회 5개, 최대 30개. 사냥 시작 시 1개를 소비합니다. 일반게임 300m 달성과 광고 기회 +3은 외부 서비스 연결 전 체험 버튼입니다. 특별 패키지에 실제 결제는 없습니다. 상품 교환소는 메인에 표시되는 장식 3종을 교환하는 시제품입니다. 이벤트 기간은 설정 예정으로 표시합니다. 설정에서 체험 코인을 받을 수 있습니다.

`progressVersion: 4`, 저장 키 `catjump-wave-score-v1`. 코인, 강화, 기회/거리, 교환 장식, 최고 웨이브, 결과, 설정을 같은 객체로 저장합니다. 구버전 재화·강화·정산 ID는 유지하며 폐기된 재장전 강화는 최초 한 번 환불합니다. 각 판 runId로 보상 중복 정산을 막고, 구매·입장 저장 실패 시 차감하지 않습니다. 서버 저장·실제 광고·원본 일반게임 연동은 없습니다.

화면은 동적 뷰포트와 안전 영역에 맞춰 페이지 스크롤 없이 표시합니다. 짧은 화면에서는 안내 영역을 압축하고 메인 상단의 톱니 버튼으로 설정에 진입합니다. `tests/layout-preview.html`은 여러 크기의 실제 iframe 뷰포트로 메인·강화·게임 표시를 확인하는 개발용 페이지입니다.
