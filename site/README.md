# 밤의 현상금 사냥 · 소스 안내

| 파일 | 역할 |
| --- | --- |
| index.html | 점수·현상금·사냥터·탄약·설정 및 결과 화면 |
| style.css | 모바일 화면, 배경, 유령 관절 애니메이션, 사격 연출 |
| app.mjs | 입력, DOM 렌더링, 오디오, 일시정지, 로컬 저장 |
| hunt-core.mjs | 시간·장전·랜덤 등장·현상금·점수·각 유령 이동 궤적 |
| ghost-art.mjs | 개별 관절을 가진 10종 SVG 아트 |
| tests/hunt-core.test.mjs | 보상, 장전, 실패, 일시정지, 랜덤 등장, 이동 및 예산 검증 |
| tests/check-ui.py | DOM ID, 모듈, 로컬 파일 참조 검사 |

공통 수치는 `hunt-core.mjs`의 DEFAULTS에 있습니다. 설정에서 변경한 수치는 이 브라우저의 다음 판에만 적용됩니다. 설정·최고 점수·최근 결과·사운드는 `catjump-bounty-hunt-v1` 키로 저장합니다. 이전 기억력 게임의 저장 데이터와 섞이지 않습니다. 이전 버전의 기본 등장 간격(0.8 / 0.3 / 0.85초)은 0.5초, 기본 시간 45초는 60초, 기본 장전 1.35초는 2.2초로 옮기며 사용자가 별도로 조정한 값은 보존합니다.

탄약은 `ammo`(탄창)와 `reserveAmmo`(예비탄)로 나눕니다. 자동 장전은 예비탄을 최대 5발 옮기며 총량을 늘리지 않습니다. 탄약 유령 보상은 발사 비용을 먼저 차감한 뒤 예비탄에 지급합니다. 마지막 한 발로 보급 유령을 맞히면 보충·장전을 먼저 처리하며, 예비탄까지 0일 때만 탄약 소진 종료합니다.

## 렌더링 및 입력

살아 있는 유령은 최대 8마리, 동시 사격 효과 노드는 최대 12개(착탄 6개와 탄피 6개)입니다. 개별 유령은 SVG의 몸통·팔·다리·꼬리를 CSS transform으로 움직이며, 이동 궤적은 단일 requestAnimationFrame에서 갱신합니다. 이동 속도는 직전 버전보다 15% 높이고 이동은 6가지 패턴만 사용하며 전체 회전·흔들림·순간이동은 없습니다. 몸통과 관절은 작은 범위에서 천천히 움직이고 수배서의 그림은 정지합니다. 추가 이미지 다운로드 없이 벡터 아트가 표시됩니다. HUD는 80ms마다 업데이트하고, 동일한 텍스트는 다시 쓰지 않습니다. 착탄에는 짧은 탄도·섬광·3개 파편·유령 반응과 점수 표시가 포함됩니다. 효과는 650ms 내 제거됩니다. 총성용 잡음 버퍼는 한 번만 만들고 재사용합니다.

영역 측정은 ResizeObserver 및 창 크기/스크롤 변경에서만 수행합니다. pointerdown은 즉시 발사하고 뒤따르는 click은 무시합니다. 키보드 활성화 click 및 Pointer Events 미지원 환경도 지원합니다. 유령이 사라진 구간에서는 입력을 받지 않습니다. 모바일에서는 게임 영역만 touch-action:none을 사용합니다.

일시정지에는 타이머·현상금 교체·장전·이동·관절 애니메이션이 함께 멈춥니다. 페이지가 숨겨질 때 자동 일시정지합니다. 먹물은 게임 전체를 불투명하게 가리지만 시간·이동·장전은 계속됩니다. 광고 체험 및 광고 보상은 제거했습니다.

## 확인 및 배포

저장소 루트에서:

```sh
node --test site/tests/*.test.mjs
python3 site/tests/check-ui.py
python3 -m http.server 8765 --directory site
```

GitHub Actions는 위 규칙 테스트와 UI 참조 검사를 통과해야 Pages에 배포합니다. 실제 브라우저에서는 시작, 터치 사격, 장전, 현상금 표시, 종료, 재도전, 일시정지, 설정, 먹물 가림과 사격 연출의 흐름을 확인합니다.
