# 현상금 사격 프로토타입 규칙

## 한 판

60초 동안 등장하는 유령을 사격합니다. 시간이 0이 되거나 폭탄을 맞히거나 탄약이 완전히 소진되면 종료합니다. 종료 이유를 1.2초 표시한 뒤 결과를 보여줍니다. 무료로 즉시 재도전할 수 있으며, 이전 버전의 기억 단계·격자·콤보·컬렉션·플레이 기회는 사용하지 않습니다.

## 점수

| 대상 | 점수 / 효과 |
| --- | --- |
| 길쭉이 | 기본 120점, 위로 나타나 멈춘 뒤 사라짐 |
| 뚱보 | 기본 100점, 제자리에서 1.4배로 커졌다가 원래 크기로 돌아옴 |
| 납작이 | 기본 140점, 좌우 직선 이동 |
| 성큼이 | 기본 130점, 위아래 직선 이동 또는 중간에서 멈춘 뒤 같은 길로 복귀 |
| 주렁이 | 기본 110점, 좌우에서 진입해 멈춘 뒤 같은 길로 복귀 |
| 황금 유령 | 1,200점 |
| 시간 유령 | 100점 + 사냥 시간 5초 |
| 탄약 유령 | 점수 없음, 예비탄 +2발(총 보유 한도 30발) |
| 폭탄 | 즉시 종료 |
| 먹물 유령 | 점수 없음, 2.3초 동안 게임 전체를 불투명하게 가림 |

일반 유령 중 1종이 현상금 표적입니다. 명중하면 기본 점수에 `200 × 배수`를 더합니다. 배수는 ×2(38%), ×3(30%), ×5(20%), ×8(9%), ×10(3%)입니다. 8초마다 표적과 배수를 새로 뽑으며 같은 표적이 연속 선정되지 않습니다. 현상금 액수와 대상은 상단 수배서에만 표시합니다. 사냥터의 일반 유령에는 표적을 알려주는 점선·WANTED 표시가 없습니다. 특별 유령에는 현상금 배수가 적용되지 않습니다.

## 등장

등장 시 황금 8.5%, 시간 8.5%, 폭탄 12%, 먹물 7%, 탄약 12%, 일반 유령 합계 52%입니다. 일반 유령은 5종 균등 확률입니다. 첫 화면은 위험 요소 없이 서로 다른 일반 유령 4마리로 시작하며 현상금 표적을 포함합니다. 이후 기본 0.5초 간격으로 한 마리씩 등장합니다. 동시 출몰 묶음은 없으며 동시 최대 8마리입니다. 패턴별 생존 시간은 약 2.1~3초입니다. 직전 버전의 6가지 패턴을 유지하며 속도만 15% 높였습니다. 중간에서 되돌아가는 패턴은 약 0.8~0.9초 정지합니다. 위로 나타나는 패턴은 짧게 올라와 멈춘 뒤 그 자리에서 흐려지며 사라집니다. 투명해진 유령에는 명중할 수 없습니다. 장전 중에도 출몰·도주는 계속됩니다.

## 탄약과 사격

한 판은 총 30발(장전 5발 + 예비 25발)로 시작합니다. 한 탄창은 최대 5발이며 명중·오발 모두 1발을 씁니다. 탄창이 비면 2.2초 동안 자동 장전하며 예비탄에서 최대 5발만 옮깁니다. 예비탄이 1~4발이면 그 수량만 장전합니다. 수동 장전 버튼과 R 단축키는 없습니다. 장전 중에는 발사되지 않고 시간·유령 이동은 계속됩니다. 일반 유령도 총알을 소모하므로 더 높은 현상금을 노릴 기회를 줄입니다. 오발의 별도 점수/시간 차감은 없습니다.

탄약 유령은 발사에 1발을 쓰고 예비탄을 2발 보충합니다(잔탄 순증 +1발). 총 보유량은 30발을 넘지 않으며 한도에 걸리면 실제 보충량만 표시합니다. 탄창을 즉시 채우지는 않습니다. 마지막 한 발로 탄약 유령을 맞히면 보충된 탄약으로 자동 장전하여 계속 플레이합니다. 탄창과 예비탄이 모두 0이면 탄약 소진을 알리고 종료합니다.

사격 시 총성과 탄도·착탄 섬광·파편·탄피가 나옵니다. 명중 시 유령이 튕겨 나가며, 오발에는 작은 착탄 자국이 남습니다. 광고 보상 시간 충전 및 즉시 장전 기능은 제거했습니다.

## 저장 및 설정

최고 점수, 최근 결과, 사운드, 조정 수치는 브라우저 로컬 저장입니다. 한 판 시간(15~120초), 장전(.4~4초), 등장 간격(.15~2초)을 설정할 수 있습니다. 기록 초기화는 확인 후 현재 프로토타입의 점수 기록만 지우며 설정은 유지합니다.
