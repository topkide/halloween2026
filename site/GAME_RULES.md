# 유령이 숨은 밤 · 게임 규칙

고정된 세로형 방에서 진행하는 2D 픽셀 기억력 사격 게임입니다. 총이나 카메라 이동 없이, 탭한 위치에 사격 이펙트와 효과음이 나옵니다.

## 한 배치의 흐름

1. **준비 → 기억:** 4행 3열, 총 12개 자리에 하얀 고양이 유령과 보라색 뿔 유령이 잠깐 나타납니다.
2. **암전 → 사격:** 유령이 숨으면 기억한 하얀 유령의 자리를 탭합니다. 원래 배치의 위치는 바뀌지 않습니다.
3. **전부 명중:** 불이 켜지고 살아남은 뿔 유령들이 덜덜 떤 뒤, 새로운 배치로 넘어갑니다.
4. **실패:** 빈자리·이미 맞힌 자리·뿔 유령을 쏘거나 시간이 끝나면 즉시 종료 판정합니다. 정해진 마지막 배치 없이 계속 도전합니다.

하얀 유령 한 마리 명중마다 기록이 1 증가합니다. 체력이나 오발 유예는 없습니다. 준비·기억·배치 전환 중에는 사격을 받지 않습니다.

## 현재 기본 밸런스

실행 시 공통 기본값은 `balance-default.json`에서 읽습니다. 아래는 현재 기본값 설명이며, 웹에서 사용자 밸런스를 적용하면 그 설정으로 플레이합니다.

| 항목 | 시작 | 상한 도달 후 |
| --- | --- | --- |
| 유령 노출 시간 | 0.50초 | 0.32초 |
| 배치별 기본 사격 시간 | 1.60초 | 0.70초 |
| 하얀 유령 | 4마리 | 6마리 |
| 고정 뿔 유령 | 3마리 | 5마리 |
| 이동 뿔 유령의 가로 이동 시간 | 680ms | 520ms |

노출·사격·이동 시간은 한 판의 경과 시간에 따라 변화하며 **30초에 상한에 도달한 뒤 유지**됩니다. 해당 배치의 수치는 배치 시작 때 정합니다. 하얀 유령과 고정 뿔 유령은 배치마다 각각 1마리씩 늘어 세 번째 배치부터 6마리·5마리를 유지합니다.

## 콤보와 시간 회복

- 명중 간격이 **450ms 이내**면 콤보가 이어집니다.
- 2콤보는 **120ms**, 3콤보는 **160ms**, 4콤보 이상은 명중마다 **200ms**를 남은 사격 시간에 더합니다.
- 첫 명중에는 시간 보너스가 없습니다. 450ms를 넘기면 콤보가 끊기고 다음 명중부터 다시 시작합니다.
- 콤보는 배치마다 초기화됩니다. 이미 시간이 끝난 뒤의 입력은 보너스로 되살릴 수 없습니다.

## 움직이는 뿔 유령

암전 중에도 보이는 별도 방해 유령입니다. 방 가장자리에서 **120ms 경고** 후 가로로 지나갑니다. 원래 기억한 유령의 위치는 그대로이며, 이 분신을 누르면 뿔 유령 오발로 즉시 종료됩니다.

처음에는 동시에 최대 1마리, **현재 2콤보 이상이거나 난이도 경과 15초 이후인 배치에서는 최대 2마리**입니다. 동시에 같은 행을 지나가지 않으며, 남은 하얀 유령이 있는 행을 이용합니다. 명중 후에는 추가 분신과 시야를 가리는 연출이 생길 수 있습니다. 배치를 끝내거나 게임이 종료되면 분신과 예약된 등장을 즉시 정리합니다.

## 타격과 실패 연출

- **명중:** 탭 위치에서 픽셀 파편·연기·명중음이 나오며, 효과가 다음 조준을 잠깐 방해합니다. 방과 터치 자리는 움직이지 않습니다.
- **허공 오발:** 방이 밝아지고 유령들이 들썩이며 “으하하핫!” 웃습니다.
- **뿔 유령 오발:** 방이 밝아지고 맞은 유령이 “킥킥킥!” 웃으며 앞으로 커집니다. 기존 코믹한 픽셀 표정을 유지합니다.
- **시간 초과:** 결과와 최고 기록을 보여주고 다시 도전할 수 있습니다.

효과음은 화면의 사운드 버튼으로 끌 수 있습니다. 기기의 움직임 줄이기 설정에서는 큰 이동·장식 연출을 줄이면서 게임 판정과 필요한 시각 정보를 유지합니다.

## 저장과 확인

최고 기록, 사운드 설정, 사용자 밸런스는 브라우저 `localStorage`에 저장됩니다. 사용자 밸런스는 JSON 저장/불러오기로 옮길 수 있으며, 공통 기본값 변경은 `balance-default.json` 수정 후 커밋·푸시해야 반영됩니다.

저장소 루트에서 검증합니다.

```sh
node --test site/tests/*.test.mjs
node site/tests/gameplay.test.cjs
```
