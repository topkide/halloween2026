# 유령이 숨은 밤 · 게임 규칙

고정된 세로형 방에서 진행하는 2D 픽셀 기억력 사격 게임입니다. 짧게 외운 위치를 빠르게 연속 사격하는 것이 핵심입니다. 총이나 카메라 이동 없이, 탭한 위치에 사격 이펙트와 효과음이 나옵니다.

**도전하기 / 다시 도전 → 간단한 게임 설명 → 게임 시작 → READY** 순서로 시작합니다. 설명을 읽는 동안에는 시간이 흐르지 않으며, 닫으면 시작 전 화면으로 돌아갑니다.

인게임은 상단의 시간 게이지·단계·일시정지 버튼과 화면 나머지를 채우는 방으로 구성합니다. 기억 구간에는 “사라지기까지”, 사격 구간에는 “찾는 시간”과 남은 초를 표시합니다. 설명 화면에는 “흰색 유령의 위치를 기억하고, 사라진 유령을 잡으세요!”라는 짧은 문장과 게임 시작 버튼을 표시합니다.

일시정지하면 방을 가리고 시간·콤보·애니메이션을 멈춥니다. “계속하기” 또는 Escape로 멈춘 순간부터 이어집니다. “처음으로”를 누르면 이번 도전을 끝내고 최고 기록을 보존한 채 시작 화면으로 돌아갑니다. 게임 종료 연출 중에는 일시정지할 수 없습니다.

## 한 배치의 흐름

1. **준비 → 기억:** 첫 배치는 0.80초, 다음 배치는 0.65초 동안 READY를 보여줍니다. 이후 4행 3열, 총 12개 자리에 하얀 고양이 유령과 보라색 뿔 유령이 짧게 올라와 제자리에 멈춥니다.
2. **암전 → 사격:** 유령이 숨으면 처음 외운 뿔 유령의 자리를 피해 하얀 유령의 자리를 빠르게 연속 탭합니다. 배치가 끝날 때까지 모든 유령과 터치 위치는 고정됩니다.
3. **전부 명중:** 불이 켜지고 살아남은 뿔 유령들이 덜덜 떤 뒤, 새로운 배치로 넘어갑니다.
4. **실패:** 빈자리·이미 맞힌 자리·뿔 유령을 쏘거나 시간이 끝나면 즉시 종료 판정합니다. 정해진 마지막 배치 없이 계속 도전합니다.

하얀 유령 한 마리 명중마다 기록이 1 증가합니다. 체력이나 오발 유예는 없습니다. 준비·기억·배치 전환 중에는 사격을 받지 않습니다.

빠른 터치를 위해 살아 있는 하얀 유령의 자리 가장자리에 16px의 보정 범위를 둡니다. 빈자리 가장자리나 좁은 틈을 살짝 벗어난 탭은 가까운 하얀 유령으로 받지만, 뿔 유령 또는 이미 맞힌 자리 안을 누르면 기존 종료 판정을 유지합니다.

## 현재 기본 밸런스

실행 시 공통 기본값은 `balance-default.json`에서 읽습니다. 아래는 현재 기본값 설명이며, 웹에서 사용자 밸런스를 적용하면 그 설정으로 플레이합니다.

| 항목 | 시작 | 상한 도달 후 |
| --- | --- | --- |
| 유령 노출 시간 | 1.20초 | 0.32초 |
| 배치별 기본 사격 시간 | 2.40초 | 0.70초 |
| 하얀 유령 | 4마리 | 6마리 |
| 고정 뿔 유령 | 3마리 | 5마리 |

노출·사격 시간은 **배치를 통과할 때마다 균등하게 줄어들며, 12번째 배치부터 최고 난이도로 유지**됩니다. 해당 배치의 수치는 배치 시작 때 정합니다. 기본 노출 시간은 1번째 1.20초 → 4번째 0.96초 → 8번째 0.64초 → 12번째 0.32초입니다. 하얀 유령과 고정 뿔 유령은 배치마다 각각 1마리씩 늘어 세 번째 배치부터 6마리·5마리를 유지합니다.

READY 준비 시간은 난이도가 올라도 고정입니다. 유령의 약 90ms 등장 연출은 위 노출 시간에 포함됩니다.

## 콤보와 시간 회복

- 명중 간격이 **450ms 이내**면 콤보가 이어집니다.
- 2콤보는 **120ms**, 3콤보는 **160ms**, 4콤보 이상은 명중마다 **200ms**를 남은 사격 시간에 더합니다.
- 첫 명중에는 시간 보너스가 없습니다. 450ms를 넘기면 콤보가 끊기고 다음 명중부터 다시 시작합니다.
- 콤보는 배치마다 초기화됩니다. 이미 시간이 끝난 뒤의 입력은 보너스로 되살릴 수 없습니다.

## 타격과 실패 연출

- **명중:** 탭 위치에서 픽셀 파편·연기·안개·명중음이 나옵니다. 효과는 시야만 잠깐 방해하며 **모든 타격 이펙트는 터치를 통과**시킵니다. 겹친 이펙트 뒤에서도 기억한 자리를 바로 이어 쏠 수 있습니다.
- **허공 오발:** 방이 밝아지고 유령들이 들썩이며 “으하하핫!” 웃습니다.
- **뿔 유령 오발:** 방이 밝아지고 맞은 유령이 “킥킥킥!” 웃으며 화면 전체로 빠르게 커집니다. 기존 코믹한 픽셀 표정을 유지합니다.
- **시간 초과:** 결과와 최고 기록을 보여주고 다시 도전할 수 있습니다.

효과음은 화면의 사운드 버튼으로 끌 수 있습니다. 기기의 움직임 줄이기 설정에서는 확대·장식 연출을 줄이면서 게임 판정과 필요한 시각 정보를 유지합니다.

## 저장과 확인

최고 기록, 사운드 설정, 사용자 밸런스는 브라우저 `localStorage`에 저장됩니다. 사용자 밸런스는 JSON 저장/불러오기로 옮길 수 있으며, 공통 기본값 변경은 `balance-default.json` 수정 후 커밋·푸시해야 반영됩니다.

저장소 루트에서 검증합니다.

```sh
node --test site/tests/*.test.mjs
node site/tests/gameplay.test.cjs
```
