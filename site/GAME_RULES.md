# 현상금 사격 프로토타입 규칙

## 한 판

45초 동안 등장하는 유령을 사격합니다. 시간이 0이 되거나 폭탄을 맞히면 종료합니다. 종료 이유를 1.2초 표시한 뒤 결과를 보여줍니다. 무료로 즉시 재도전할 수 있으며, 이전 버전의 기억 단계·격자·콤보·컬렉션·플레이 기회는 사용하지 않습니다.

## 점수

| 대상 | 점수 / 효과 |
| --- | --- |
| 길쭉이 | 기본 120점, 몸을 늘이며 지그재그 |
| 뚱보 | 기본 100점, 배가 출렁이며 통통 튐 |
| 납작이 | 기본 140점, 미끄러지고 잠깐 사라짐 |
| 성큼이 | 기본 130점, 다리를 번갈아 움직이며 대각선 이동 |
| 주렁이 | 기본 110점, 팔을 휘두르며 중간에 방향 전환 |
| 황금 유령 | 1,200점 |
| 시간 유령 | 100점 + 사냥 시간 5초 |
| 폭탄 | 즉시 종료 |
| 먹물 유령 | 점수 없음, 2.3초 시야 방해 |

일반 유령 중 1종이 현상금 표적입니다. 명중하면 기본 점수에 `200 × 배수`를 더합니다. 배수는 ×2(38%), ×3(30%), ×5(20%), ×8(9%), ×10(3%)입니다. 8초마다 표적과 배수를 새로 뽑으며 같은 표적이 연속 선정되지 않습니다. 현상금 액수는 포스터에 표시하고 표적 주변에는 점선과 WANTED 표시를 붙입니다. 특별 유령에는 현상금 배수가 적용되지 않습니다.

## 등장

등장 시 황금 8.5%, 시간 8.5%, 폭탄 12%, 먹물 7%, 일반 유령 합계 64%입니다. 일반 유령은 5종 균등 확률입니다. 첫 화면은 위험 요소 없이 서로 다른 일반 유령 4마리로 시작하며 현상금 표적을 포함합니다. 이후 기본 0.8초 간격에 0.7~1.3배 편차를 두고 등장합니다. 생존 시간·진입 방향·세로 위치도 달라집니다. 동시 최대 7마리입니다.

## 탄약과 보급

한 탄창은 5발입니다. 명중·오발 모두 1발을 쓰며 0발이면 1.35초 자동 장전합니다. 버튼/R로 미리 장전할 수도 있습니다. 장전 중에는 발사되지 않고 남은 게임 시간은 계속 흐릅니다. 오발의 별도 점수/시간 차감은 없습니다.

광고 체험은 3초 동안 플레이 시간을 멈춘 후 시간 10초 또는 탄약 5발을 지급합니다. 두 보급은 각각 판당 1회이며 취소 시 사용 횟수를 쓰지 않습니다. 실제 광고 SDK는 연결하지 않았습니다.

## 저장 및 설정

최고 점수, 최근 결과, 사운드, 조정 수치는 브라우저 로컬 저장입니다. 한 판 시간(15~120초), 장전(.4~4초), 등장 간격(.35~2초)을 설정할 수 있습니다. 기록 초기화는 확인 후 현재 프로토타입의 점수 기록만 지우며 설정은 유지합니다.
