# 캣점프 할로윈 · PLAY TEST 10

학교 유령 사격장 최신 기획을 반영한 정적 프로토타입입니다. `index.html`을 HTTP 서버에서 엽니다. 광고는 실제 연결 없이 완료 보상만 모의합니다.

## 최신 규칙
- 일반 유령: 1회 터치 처치, 자연 소멸 시 남은 시간 감소.
- 폭탄 유령: 터치 시 체력 1 감소. 자연 소멸 또는 손전등 처치 시 생성 시점 일반 유령 점수 지급. 고양이 친구는 제거했습니다.
- 보스: 최대 1마리. 직선 이동과 피격 순간이동, 여러 번 터치 처치. 처치 시 추가 시간과 점수, 처치 후 재등장 대기. 예고 후 반투명 얼굴이 반복해서 시야를 가립니다. 얼굴은 터치를 통과시키고 뒤의 유령을 계속 잡을 수 있습니다.
- 손전등: 지속 시간 동안 현재 및 새로 나타난 모든 유령을 자동 처치합니다. 보스 즉사와 시간 보상, 폭탄 점수가 포함됩니다.
- 부적: 별도 소환 간격 테이블 적용, 폭탄 제거 및 생성 중단, 보스 능력 중단. 허공 터치 체력 감소와 일반 유령 놓침 시간 감소를 방지합니다. 종료 시 보스 외 전부 정리하고 보스 능력 대기를 초기화합니다. 종료 후 소수점 설정 가능한 허공 터치 보호가 이어집니다. 정리에는 보상/페널티가 없습니다.
- 아이템: 각각 보유 최대 1개, 한 판에 각 1회 사용, 동시 사용 가능. 미사용분은 다음 판으로 이월합니다.
- 이어하기: 한 판에 광고 보상 1회. 난이도 시간 30초 되감기, 체력/남은 시간 완전 회복, 무료 부적. 보유 아이템이나 수동 사용 횟수를 소비하지 않습니다. 이전 필드는 보상 없이 정리합니다.
- 컬렉션: 교과서, 실내화, 농구공, 배드민턴채, 책가방, 축구공, 필통, 리코더, 숙제종이. 이어하기를 포함한 최종 결과에서 조건을 충족한 미보유 물품을 각각 한 번 추첨합니다. 한 판 최대 2개. 3개 이상 당첨되면 당첨 목록 중 무작위 2개를 지급합니다. 결과를 다시 열어도 재추첨하지 않습니다.

## 시간과 밸런스
`clock`은 일시정지를 제외한 누적 플레이 시간(아이템·능력·소환 예약 기준), `elapsed`는 이어하기 시 되감는 난이도 시간, `peakTime`은 해당 판 최고 도달 난이도 시간입니다. 컬렉션은 되감기로 이미 도달한 조건을 잃지 않도록 `peakTime`을 사용합니다.

일반/폭탄 유령은 별도 최대 마릿수 제한 없이 소환 간격과 체류 시간으로 밀도가 결정됩니다. 생성 시점의 체류/점수/놓침 페널티를 유지합니다. 마지막 테이블 행 이후에는 동일 값을 유지합니다.

초기값은 테스트용이며 빠르게 밸런스 DB(`catjump-balance-v6-fast.json`, `balance-default-v6.json`과 동일)를 반영했습니다. 시작 30초, 보스 첫 등장 5초, 재등장 6초, 처치 보상 8초이며 일반·폭탄·부적 테이블은 0/20/40/60초 구간으로 나뉩니다. 컬렉션 확률도 테스트용 8~20%이며 밸런스에서 0.05% 등으로 수정할 수 있습니다.

밸런스는 v6 JSON으로 내보내고 다른 브라우저/주소에서 불러올 수 있습니다. 구버전 v1~v5는 구조가 달라 적용하지 않으며 이전 저장본은 삭제하지 않습니다. 아이템/컬렉션은 브라우저 로컬 저장입니다. 계정 간 동기화는 없습니다.
