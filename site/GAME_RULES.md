# 유령 소탕 대작전! · 게임 규칙

고정된 세로형 방에서 진행하는 2D 픽셀 기억력 사격 게임입니다. 짧게 외운 위치를 빠르게 연속 사격하는 것이 핵심입니다. 총이나 카메라 이동 없이, 탭한 위치에 사격 이펙트와 효과음이 나옵니다.

## 이벤트 메인

시작 화면은 **유령 소탕 대작전!** 이벤트 로비입니다. 제목·기간, 특별 패키지, 유령 구슬, 할로윈 배경, 플레이 기회 게이지, 상품 교환소·컬렉션·게임 시작 버튼을 배치합니다. 일정은 미정이며 거리 20/300m는 화면 체험용 예시입니다. 유령 구슬은 0개에서 시작해 게임 보상을 합산합니다. 일반게임의 거리와 실제 광고·구매·상품 교환은 연결되어 있지 않습니다.

플레이 기회는 첫 방문에 3회이며 이 브라우저에 저장됩니다. 설명 확인 후 실제 게임을 시작할 때 1회를 사용합니다. “기회 +3”은 체험 안내를 확인하면 최대 30회까지 충전합니다. 설명 닫기·일시정지·재개·메인 복귀로 추가 차감하지 않습니다. 게임 종료 화면의 “이벤트 메인”으로 로비에 돌아갈 수 있습니다.

**메인의 게임 시작 / 다시 도전 → 간단한 게임 설명 → 게임 시작 → READY** 순서로 시작합니다. 설명을 읽는 동안에는 시간이 흐르지 않으며, 닫으면 시작 전 화면으로 돌아갑니다.

인게임은 상단의 시간 게이지·일시정지 버튼과 화면 나머지를 채우는 방으로 구성합니다. 단계 이름·찾은 유령 수·수집 수·남은 초는 화면에 표시하지 않습니다. 게이지 아래에는 기본 코인 단가를 콤보 코인 배수 왼쪽에 나란히 배치하고, 오른쪽에는 이번 판 누적 코인을 표시합니다. READY 아래의 격자 크기·노출 시간 안내는 표시하지 않습니다. 설명 화면에는 “흰색 유령의 위치를 기억하고, 사라진 유령을 잡으세요!”와 “빈자리는 시간 감소, 폭탄 유령은 바로 종료!”라는 안내를 표시합니다.

일시정지하면 방을 가리고 시간·콤보·애니메이션을 멈춥니다. “계속하기” 또는 Escape로 멈춘 순간부터 이어집니다. “처음으로”를 누르면 이번 도전을 끝내고 최고 기록을 보존한 채 시작 화면으로 돌아갑니다. 게임 종료 연출 중에는 일시정지할 수 없습니다.

## 한 배치의 흐름

1. **준비 → 기억:** 첫 배치는 0.80초, 다음 배치는 0.65초 동안 READY를 보여줍니다. 이후 유령이 올라와 제자리에 멈춥니다. 1~5번째 배치는 3×3, 6~12번째는 4×4, 13번째부터는 5×5입니다. 이후 방과 유령 크기는 고정됩니다.
2. **암전 → 사격:** 유령이 숨으면 처음 외운 폭탄 유령의 자리를 피해 하얀 유령의 자리를 빠르게 연속 탭합니다. 배치가 끝날 때까지 모든 유령과 터치 위치는 고정됩니다.
3. **전부 명중:** 불이 켜지고 살아남은 폭탄 유령들이 덜덜 떤 뒤, 새로운 배치로 넘어갑니다.
4. **실수와 실패:** 빈자리·이미 맞힌 자리·방의 여백을 쏘면 남은 시간이 0.40초 줄고 콤보가 초기화됩니다. 시간이 남으면 바로 계속 사격하며 콤보로 만회할 수 있습니다. 폭탄 유령을 쏘거나 시간이 0이 되면 즉시 실패합니다. 정해진 마지막 배치 없이 계속 도전합니다.

모든 자리는 동일한 크기의 카드형 칸으로 표시합니다. 각 칸 전체에 붉은 보라색 배경과 선명한 테두리가 있으며, 이 테두리는 실제 터치 영역의 경계입니다. 3×3·4×4·5×5 모두 칸 사이에 빈틈 없이 표시하고 암전 중에도 가이드를 유지합니다. 아직 쏘지 않은 칸은 유령 종류나 빈자리 여부와 관계없이 똑같이 보입니다. 명중한 칸은 청록색과 ✓, 오발한 칸은 붉은색과 ×로 구분하고, 다음 배치에서는 초기화합니다.

하얀 유령 한 마리 명중마다 기록이 1 증가합니다. 실수 후 대기시간이나 시간 정지는 없으며, 암전과 숨겨진 배치를 유지합니다. 준비·기억·배치 전환 중에는 사격을 받지 않습니다.

사격은 손가락을 떼는 클릭이 아니라 화면에 닿는 순간 처리합니다. 두 손가락이 잠깐 겹쳐도 각각의 터치를 받으며, 터치 간 대기시간은 없습니다. 손을 떼거나 드래그하는 동작은 추가 발사하지 않습니다. 게임 방 안에서는 스크롤·확대 제스처를 막아 연속 입력을 유지하고, 메뉴 조작은 기존 방식을 사용합니다. 마우스는 왼쪽 버튼을 누르는 순간 발사하고 키보드 조작도 지원합니다.

빠른 터치를 위해 살아 있는 하얀 유령의 자리 가장자리에 16px의 보정 범위를 둡니다. 빈자리 가장자리나 좁은 틈을 살짝 벗어난 탭은 가까운 하얀 유령으로 받지만, 폭탄 유령 또는 이미 맞힌 자리 안을 누르면 다른 목표로 바꾸지 않습니다. 각각 즉시 실패·시간 차감을 적용합니다.

## 현재 기본 밸런스

실행 시 공통 기본값은 `balance-default.json`에서 읽습니다. 아래는 현재 기본값 설명이며, 웹에서 사용자 밸런스를 적용하면 그 설정으로 플레이합니다.

| 항목 | 시작 | 상한 도달 후 |
| --- | --- | --- |
| 유령 노출 시간 | 1.60초 | 0.45초 |
| 배치별 기본 사격 시간 | 2.80초 | 0.85초 |
| 하얀 유령 | 3마리 | 10마리 |
| 고정 폭탄 유령 | 1마리 | 9마리 |

노출·사격 시간은 **배치를 통과할 때마다 균등하게 줄어들며, 24번째 배치부터 같은 최솟값을 유지**합니다. 흰색은 3배치마다, 폭탄 유령은 2배치마다 1마리씩 늘며 현재 방의 수용 범위 안에서 생성합니다. 13번째부터 5×5 크기를 고정하고 목표 수·폭탄 유령 수와 목표 사이 거리를 점진적으로 늘립니다. 배치는 매번 새로 섞이고, 24번째 이후에도 무한히 이어집니다.

READY 준비 시간은 난이도가 올라도 고정입니다. 첫 배치는 0.80초 준비하며, 이후에는 마지막 명중 연출 0.30초 → 불이 켜진 상태에서 폭탄 유령이 떠는 시간 0.70초 → READY 1.00초 순서로 진행합니다. 클리어부터 다음 유령 등장까지 총 2초의 여유를 둡니다. 유령의 약 90ms 등장 연출은 위 노출 시간에 포함됩니다.

## 콤보와 시간 회복

- 명중 간격이 **220ms 이내**여야 콤보가 이어집니다.
- 2콤보는 **120ms**, 3콤보는 **160ms**, 4콤보 이상은 명중마다 **200ms**를 남은 사격 시간에 더합니다.
- 첫 명중에는 시간 보너스가 없습니다. 220ms를 넘기면 콤보가 끊기고 다음 명중부터 다시 시작합니다.
- 콤보는 배치마다 초기화됩니다. 이미 시간이 끝난 뒤의 입력은 보너스로 되살릴 수 없습니다.
- 3~5콤보는 코인 **×2**, 6~8콤보는 **×3**, 9콤보 이상은 **×4**입니다. 해당 콤보에 도달한 명중부터 기본 코인 단가에 배수를 곱해 지급합니다. 콤보가 끊기거나 빈자리를 쏘면 배수가 ×1로 돌아오며 이미 얻은 코인은 유지합니다.
- 빈자리 사격은 남은 시간에서 0.40초를 즉시 차감하고 콤보를 끊습니다. 다시 첫 명중부터 시작하며 빠르게 두 번째를 맞혀야 보너스를 얻습니다. 차감과 동시에 시간이 소진되면 콤보로 되살릴 수 없습니다. 차감량은 밸런스의 `difficulty.missPenalty`에서 조절합니다.
- 연속 콤보 중에는 방 상단 중앙에 큰 콤보 숫자와 남은 연결 시간 막대가 나타납니다. 매 명중마다 숫자가 튀어 오르고, 3·6·9콤보마다 금색·주황색·분홍색으로 연출이 강화됩니다. 명중 숫자·파편·빛의 크기도 커지며, 마지막 명중은 클리어 연출 동안 유지합니다. 표시 크기에는 상한을 두고 모든 효과는 터치를 통과합니다. 유령의 위치와 방은 움직이지 않습니다.

## 이어하기와 결과

첫 실패 연출이 끝나면 이어하기를 제안합니다. “광고 시청 후 계속 플레이할 수 있어요.”와 “(난이도 일부 하락, 기본 코인 개수 유지)”를 표시합니다. 프로토타입의 광고는 **3초 체험**이며 실제 광고 SDK는 연결되어 있지 않습니다.

- 이어하기는 한 판에 한 번입니다. 광고 체험 완료 시 3배치만큼 난이도를 낮추고, 남은 도전의 기억·사격 시간을 15% 늘립니다. 새 배치부터 재개하며 잡은 횟수·수집품·모은 코인과 도달한 코인 단가를 보존합니다. 추가 기회는 쓰지 않습니다.
- 뒤로 가기 또는 Escape를 누르거나, 한 번 이어한 뒤 다시 실패하면 결과창을 표시합니다.
- 결과는 플레이 시간, 잡은 유령 수, 이번 판 컬렉션(최대 2개), 획득 보상을 보여줍니다. 획득 점수나 콤보 보너스·최고 기본 단가 안내는 표시하지 않습니다.
- 유령을 잡은 순간의 단가로 코인을 쌓아 최종 결과에서 한 번 지급합니다. 결과의 보상 2배 광고 체험을 끝내면 모은 총액을 한 번 더 지급합니다. 체험 도중 나가면 추가 보상은 없습니다.
- 플레이 시간은 준비·기억·사격·배치 전환을 포함하며 일시정지·실패 연출·이어하기 선택·광고 체험 시간은 제외합니다.

## 깊이 진행할수록 커지는 코인 보상

| 이번 판 도달한 최고 배치 | 유령 한 마리당 코인 |
| --- | --- |
| 1~5번째 | 1 |
| 6~10번째 | 2 |
| 11~15번째 | 3 |
| 16~20번째 | 4 |
| 이후 | 5배치마다 1코인씩 증가 |

위 표는 콤보 배수 적용 전 기본 단가입니다. 인게임 시간 막대에는 기본 단가, 그 아래에는 현재 콤보 코인 배수를 표시합니다. 명중 이펙트에는 배수를 적용한 실제 획득량을 보여줍니다. 일시정지 버튼 아래에는 코인 아이콘과 함께 이번 판 획득 합계를 실시간으로 표시합니다. 흰색·컬렉션 유령 모두 같은 계산을 적용하며, 빈자리·이미 잡은 자리·폭탄 유령 사격에는 코인을 주지 않습니다. 예를 들어 기본 3코인일 때 6콤보 명중은 9코인을 얻습니다. 이전에 잡은 유령의 보상을 새 단가나 배수로 소급하지 않습니다.

이어하기로 난이도가 내려가도 그 판의 최고 도달 기본 단가를 유지하며 콤보 배수는 ×1부터 다시 시작합니다. 예를 들어 13번째에서 기본 3코인 단가를 얻고 10번째 난이도로 돌아가도 기본 3코인을 계속 받습니다. 새 판은 기본 1코인·배수 ×1부터 다시 시작합니다. 크기·시간의 난이도 상한 이후에도 더 깊은 배치의 코인 단가는 계속 증가합니다.

## 희귀 컬렉션

매 배치 **5% 확률**로 아이템을 든 유령 한 마리가 빈자리에 나타납니다. 일반 유령 노출 시간의 절반 만에 먼저 숨으며, 암전 후 기억한 자리를 쏘면 획득합니다. 잡지 않아도 실패하지 않으며, 일반 흰색 유령만 모두 잡으면 배치를 완료합니다.

컬렉션은 한 판 전체에서 **최대 2개**만 얻고 이어하기로 초기화되지 않습니다. 미수집 9종 중 무작위로 등장하므로 중복은 없으며 전부 모으면 더 나타나지 않습니다. 명중 시 즉시 브라우저에 저장하고 결과에 해당 판 획득품을 표시합니다. 컬렉션 유령도 잡은 횟수·콤보에 포함됩니다.

로비의 3×3 앨범에는 잠김 상태, 선택한 수집품 이름, 수집 진행도를 표시합니다. 9종을 모으면 “유령 고양이” 보상을 한 번 받을 수 있습니다. 캐릭터 보상은 이 프로토타입의 수령 기록이며 본 게임의 캐릭터 지급과 연동되어 있지 않습니다.

## 타격과 실패 연출

- **명중:** 탭 위치에서 픽셀 파편·연기·안개·명중음이 나옵니다. 효과는 시야만 잠깐 방해하며 **모든 타격 이펙트는 터치를 통과**시킵니다. 겹친 이펙트 뒤에서도 기억한 자리를 바로 이어 쏠 수 있습니다.
- **허공 오발:** 사격 위치에 “MISS −0.40초 / 으하하!” 표시와 웃음소리가 나옵니다. 방과 유령은 계속 어둡게 숨겨진 상태이며 사격을 막지 않습니다.
- **폭탄 유령 오발:** 검은 폭탄 몸체·불붙은 도화선·경고 무늬로 금지 목표를 구분합니다. 방이 밝아지고 맞은 유령이 “킥킥킥!” 웃으며 화면 전체로 빠르게 커집니다. 코믹한 픽셀 표정으로 너무 무섭지 않게 표현합니다.
- **시간 초과:** 남은 이어하기 기회에 따라 이어하기 또는 결과를 보여줍니다.

효과음은 화면의 사운드 버튼으로 끌 수 있습니다. 기기의 움직임 줄이기 설정에서는 확대·장식 연출을 줄이면서 게임 판정과 필요한 시각 정보를 유지합니다.

## 저장과 확인

잡은 최고 횟수, 사운드 설정, 사용자 밸런스, 플레이 기회, 구슬 잔액, 컬렉션과 캐릭터 수령 여부는 브라우저 `localStorage`에 저장됩니다. 계정 간 동기화는 없습니다. 사용자 밸런스는 JSON 저장/불러오기로 옮길 수 있으며, 공통 기본값 변경은 `balance-default.json` 수정 후 커밋·푸시해야 반영됩니다.

저장소 루트에서 검증합니다.

```sh
node --test site/tests/*.test.mjs
node site/tests/gameplay.test.cjs
```
